# RobotCore-Lite

Research-first ROS 2 communication transport benchmark and framework. This is a **fresh implementation**, inspired by previous research, not recovered source. **RobotCore Telemetry is a separate project.**

Phase 1 establishes a controlled ROS 2 DDS baseline; alternative transports are planned and **no performance improvement is claimed**.

Target: Ubuntu 24.04 / ROS 2 Jazzy (verify target setup before running).
